================================================================
PANDUAN PENGGUNAAN PRINT BRIDGE ANTREAN RS (WINDOWS)
DUKUNGAN MULTI-KOMPUTER (BEBAS 1 LEMBAR ATAU 2 RANGKAP TIAP PC)
================================================================

Folder ini berisi tool Print Bridge agar printer thermal USB di komputer
Windows dapat mencetak tiket antrean secara OTOMATIS & LANGSUNG
(Silent Printing tanpa dialog print browser sama sekali).

KINI MENDUKUNG PENGATURAN BERBEDA PADA SETIAP KOMPUTER:
Misalnya:
- Komputer Kiosk 1 mencetak 1 Lembar saja (Pasien)
- Komputer Kiosk 2 mencetak 2 Rangkap (Pasien & Petugas/Poli)

================================================================
CARA MENGATUR JUMLAH LEMBAR CETAK PER KOMPUTER:
================================================================

CARA A: LEWAT TOMBOL DI LAYAR KIOSK (PALING MUDAH & CEPAT)
1. Buka halaman Kiosk di komputer tersebut.
2. Di bagian atas layar (sebelah badge Direct Silent Print), terdapat tombol:
   [ PC Ini: 1 Lembar (Standar) / 2 Rangkap (Copy 2) ]
3. Cukup KLIK tombol tersebut untuk mengganti mode komputer itu.
4. Pengaturan akan tersimpan permanen khusus di komputer tersebut!

----------------------------------------------------------------

CARA B: LEWAT FILE BATCH DI FOLDER PRINT BRIDGE INI
1. JIKA INGIN KOMPUTER INI MENCETAK 1 LEMBAR (1 COPY):
   - Klik 2x 'atur-ke-1copy.bat'
   - Atau pasang autostart: klik 2x 'pasang-autostart-1copy.bat'

2. JIKA INGIN KOMPUTER INI MENCETAK 2 RANGKAP (PASIEN & POLI):
   - Klik 2x 'atur-ke-2copy.bat'
   - Atau pasang autostart: klik 2x 'pasang-autostart-copy2.bat'

3. JIKA INGIN MENJALANKAN MANUAL DENGAN JENDELA TERLIHAT:
   - 1 Lembar  : Klik 2x 'jalankan-printer-bridge-1copy.bat'
   - 2 Rangkap : Klik 2x 'jalankan-printer-bridge-copy2.bat'

================================================================
CARA AGAR OTOMATIS JALAN SAAT WINDOWS MENYALA (AUTOSTART BACKGROUND):
================================================================
1. Jalankan 'pasang-autostart-background.bat'.
2. Pilih mode [1] untuk 1 lembar atau [2] untuk 2 rangkap.
3. Print Bridge akan otomatis aktif di latar belakang setiap kali komputer dinyalakan.

================================================================
PERINTAH PENDUKUNG LAINNYA:
================================================================
- 'cek-status.bat'               : Mengecek apakah Print Bridge aktif & printer apa yang terhubung.
- 'hentikan-printer-bridge.bat'  : Menghentikan proses background jika ingin dimatikan sementara.
- 'hapus-autostart.bat'          : Mencabut Print Bridge dari Windows Startup.
================================================================
